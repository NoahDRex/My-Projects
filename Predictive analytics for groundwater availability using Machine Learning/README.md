AquaPredict is a full-stack Machine Learning web application that predicts groundwater depth levels using real monitoring data from the Colorado Division of Water Resources. It merges well site metadata (location, well depth, aquifer type, county) with decades of historical water level measurements into a single cleaned dataset of over 22,000 records. Using this data, the system trains and compares five regression models — Linear Regression, Decision Tree, Random Forest, Gradient Boosting, and XGBoost — automatically selecting the best performer based on R² score (XGBoost, with 99.75% accuracy) and saving it for reuse. The trained model powers a responsive Flask-based website built with Bootstrap 5, where users can enter well parameters like coordinates, well depth, and aquifer type through an auto-generated form and instantly receive a predicted groundwater depth, along with an interactive dashboard showing model comparisons, feature importance, correlation heatmaps, and prediction history. The project demonstrates a complete end-to-end ML workflow — from raw data processing to a deployable, user-friendly prediction tool — built entirely with Python, Flask, and Scikit-learn.
